# Registro de Decisões do Produto

Este diretório registra as decisões relevantes tomadas durante a descoberta,
definição e desenvolvimento da Plataforma de Atendimento Inteligente.

## Objetivo

Manter uma fonte consultável de decisões, evitando:
- Reabrir assuntos já decididos sem justificativa.
- Perder decisões tomadas durante as conversas.
- Criar contradições entre os documentos.
- Confundir hipóteses com decisões aprovadas.

## Convenção

Cada decisão deve possuir:
- Identificador sequencial.
- Data.
- Status: proposta, aprovada ou substituída.
- Contexto e problema.
- Decisão tomada.
- Consequências e limites.
- Referências aos documentos relacionados.

## Regra de manutenção

Decisões aprovadas não devem ser reabertas sem uma razão explícita.
Quando uma decisão mudar, registrar uma nova decisão e indicar qual foi substituída.

Os documentos funcionais devem refletir as decisões vigentes.
